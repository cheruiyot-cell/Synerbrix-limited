Synerbrix Limited – Digital Solutions Website

A clean, professional, single‑page business website for Synerbrix Limited, a technology service provider offering web development, IT support, networking, cybersecurity, Wi‑Fi, and CCTV solutions.

This project is built with pure HTML, CSS, and JavaScript (no external frameworks or build tools) and is fully responsive, SEO‑friendly, and ready for production deployment.

---

🚀 Features

· Fully Responsive – Works on all screen sizes (mobile, tablet, desktop).
· SEO & SEM Optimized – Includes meta tags, Open Graph, Twitter cards, and structured JSON‑LD data (Schema.org) for better search engine visibility.
· Sticky Navigation – Smooth scroll and active state tracking.
· Mobile‑Friendly Menu – Hamburger toggle with animated icon.
· Hero Section – Engaging call‑to‑action with WhatsApp integration.
· Service Cards – Seven service areas with hover effects and a highlighted CCTV card.
· Contact Form – Client‑side validation with simulated submission and automatic WhatsApp pre‑fill.
· WhatsApp Integration – One‑click chat and form backup.
· M‑Pesa Payment Details – Displayed prominently for Kenyan customers.
· Unsplash Images – High‑quality, royalty‑free image used for the hero graphic.

---

🛠️ Technologies Used

· HTML5 – Semantic markup.
· CSS3 – Custom properties (variables), Flexbox, Grid, transitions, and responsive breakpoints.
· JavaScript (Vanilla) – DOM manipulation, event handling, throttling, and form validation.
· Font Awesome 6 – Icon library.
· Unsplash – Free stock images.

🧩 How to Use

1. Clone the repository or download the index.html file.
2. Open index.html in any modern web browser.
3. No build steps or server required – it works out of the box.
